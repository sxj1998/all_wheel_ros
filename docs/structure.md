## Notes

- `src/` contains ROS2 packages.
- `docs/` contains project documentation and generated diagrams.
- `maps/` contains the active navigation maps. The current kept maps are `maze2` and `my_slam_map`.
- `build/`, `install/`, and `log/` are generated by `colcon` and should stay untracked.

## Build From Workspace Root

```bash
cd /home/shexingju/work/ROS2
source /opt/ros/humble/setup.bash
colcon build --symlink-install
source install/setup.bash
```

## Launch

```bash
ros2 launch ros2_all_wheel_sim gazebo_sim.launch.py world:=maze2
ros2 launch ros2_all_wheel_sim slam_gazebo_sim.launch.py world:=maze2
ros2 launch ros2_all_wheel_sim navigation_gazebo_sim.launch.py world:=maze2 map:=my_slam_map
```
